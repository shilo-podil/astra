# Astra AI

בוט AI חכם עם קטגוריות - בנוי על Anthropic Claude API.

## איך משתמשים

1. פתח את האתר
2. לחץ על ⚙️ **הגדרות**
3. הכנס Anthropic API Key מ-[console.anthropic.com](https://console.anthropic.com)
4. בחר קטגוריה (קוד, כתיבה, לימוד וכו') ותתחיל לדבר

המפתח נשמר רק בדפדפן שלך (localStorage).

## הרצה מקומית

פותחים את `index.html` בדפדפן. זהו.
